Firm-day Attention and Sentiment Data

First principal components (PCs) of attention and sentiment, 2012–2021.

Mendeley dataset

The data are in the Social Signal Index folder of the Mendeley dataset.

If you use these data, please cite the following publication, which develops, validates and uses the measures:

“The Social Signal” by J. Anthony Cookson, Runjing Lu, Will Mullins, and Marina Niessner, Journal of Financial Economics, Vol. 158 (August 2024), 103870.

Firm-day Investor Disagreement Data
